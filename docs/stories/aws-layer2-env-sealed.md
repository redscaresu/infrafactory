# Layer 2's AWS env is complete and sealed, proven by real tofu on fakeaws with the network sealed

cloudEnv (internal/cli/test_command.go:102-171, AWS keys at :113-116) sets AWS_ENDPOINT_URL_<SVC> for the 10 services in the endpoints map (generate_command.go:546-556) plus STS and SSM. The spellings are fakeaws's, which the real provider honours in fakeaws CI (../fakeaws examples/smoke_env_test.go:26-39): EC2, IAM, EKS, RDS, SQS, DYNAMODB, SECRETS_MANAGER, KMS, ROUTE_53, S3, STS, SSM. S3 goes to cfg.S3.URL, else fakeaws/s3. The global AWS_ENDPOINT_URL is a dead loopback constant. AWS_CONFIG_FILE and AWS_SHARED_CREDENTIALS_FILE reuse harness's not-exist paths (awsSealedConfigFile, aws_sealed_env.go:17,52, exported). An empty cfg.Fakeaws.URL sends every endpoint to the dead constant. awsRegion(cfg) (aws.region, else us-east-1) sets AWS_REGION and every regional path, and config.go:135-136 is amended. harness.Layer2StripEnv ["AWS_*"] is defined in internal/harness/static.go beside Command. It is set on every Command in static.go:102-130, mock_deploy.go:113-158 and destroy.go:55. The provider block is untouched in this story (it still carries endpoints and skip_*). e2e helper SealNetwork(t): once per test binary it runs `tofu providers mirror` for hashicorp/aws 5.100.0 into a cache dir. It then sets TF_CLI_CONFIG_FILE to a filesystem_mirror, with direct excluded for hashicorp/aws, and HTTPS_PROXY/HTTP_PROXY to a dead loopback with NO_PROXY=127.0.0.1,localhost. RunInfrafactory runs in-process (helpers.go:368), so tofu inherits all of this: init needs no network, and any request not bound for loopback dies at the proxy. This is fakeaws's smokeEnv pattern (smoke_env_test.go:44-66). Two sealed e2e tests join the CI fakeaws-clone step (.github/workflows/ci.yml:86-102) at the current FAKEAWS_SHA 76ea106.
